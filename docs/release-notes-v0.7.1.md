# Release notes 0.7.1

mojiroku 0.7.1 is a maintenance release.

- **Download and update links:** the download page, in-app updates and the source code
  link in `NOTICE` now point at the project's current GitHub account.
- **Secure connections:** the TLS libraries used for model downloads, cloud summaries
  (your own API key), and the Notion, Slack and Google integrations are updated.
